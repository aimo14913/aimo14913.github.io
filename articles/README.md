# aimo 官網文章區使用方式

## 每新增一篇文章，要完成 5 件事

1. 複製 `codex-work-delivery.html`，改成新的英文網址檔名。
2. 修改標題、摘要、作者、發布日、更新日、分類與正文。
3. 在 `index.html` 增加文章卡片。
4. 在網站根目錄的 `sitemap.xml`、`llms.txt`、`llms-full.txt` 增加文章網址與摘要。
5. 在 `feed.xml` 增加 RSS 項目，再執行本機檢查。

## 每篇文章必填資料

- 一個讀者真的會問的文章標題
- 120 至 160 字內的搜尋摘要
- 固定網址（canonical）
- 作者：aimo 艾摸
- 原始發布日期與最後更新日期
- 文章分類與 3 至 5 個主題詞
- 100 字內先回答問題的摘要
- 可獨立理解的 H2、H3 段落
- 真實案例、數字或外部資料的來源；沒有來源就不要補數字
- 作者介紹與回到文章首頁的連結

## 發布前人工確認

- 文章是 aimo 本人寫過或已明確核准的內容。
- 個人經驗、案例、價格、日期與成果沒有被 AI 擅自改寫。
- 沒有「第一、最好、保證、一定有效」等無法證明的承諾。
- 手機與電腦都能正常閱讀。
- 新網址已加入文章首頁、網站地圖、LLM 說明檔與 RSS。

SEO 與 GEO 的目標是讓內容更容易被搜尋系統和生成式 AI 理解、檢索與引用，不保證排名、推薦或流量。
